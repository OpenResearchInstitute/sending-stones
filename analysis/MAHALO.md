# MAHALO — Mesh Assessment of Heard And Lost Offerings

Analysis notebook for Sending Stones trials (named for ALOHAnet, whose ~18%
shared-channel ceiling is where this argument began. -Abramson, 1970).

Inputs: `trials.csv`, `trials_h5.csv` from `code/collate.py`.
Pre-registered analyses per DESIGN §6: H1 knee-finding, H2 paired preset
comparison, H3 aperture/path-class, H4 hop-stratified starvation, H5 capture
threshold logistic fit. Jupyter notebook lands here at Phase 0.
